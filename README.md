# Interview.AI

Interview.AI is a web application designed to help students improve their interview preparation. The platform allows users to analyze resumes, upload mock interview videos, and receive AI-powered feedback to identify areas for improvement.

I built this project while learning full-stack development and exploring how AI can be used to solve real-world problems faced by students during placement preparation.

Tech Stack

Frontend
React
TypeScript
Tailwind CSS
Vite

Backend
Node.js
Express.js

Database
MongoDB Atlas

AI Services
Google Gemini API
Groq API

Features

Resume Analysis

- Upload a resume
- Get feedback on content and structure
- Receive suggestions for improvement

Interview Analysis

- Upload a mock interview video
- Get feedback on communication and confidence
- Review performance insights

Installation

Clone the repository

git clone <repository-url>

Install dependencies

npm install

Create a .env file and add your API keys

GEMINI_API_KEY=your_api_key

Start the development server

npm run dev

About the Project

The main objective of this project is to provide students with a simple platform for practicing interviews and improving their resumes before placement drives. It also helped me gain hands-on experience with React, Node.js, MongoDB, and AI API integration.
